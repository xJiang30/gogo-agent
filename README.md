# Gogo Agent

AI-native travel planning MVP focused on conversational plan generation, an
editable Trip Board, map visualization, and proposal-first AI assistance.

## Prototype

Open `index.html` in a browser or serve the directory with a static HTTP server.

## Manual Agent Testing

Run the five-round manual acceptance test:

```powershell
python manual_agent_playground.py
```

Use `MANUAL_FIVE_ROUND_TEST_SET.md` to understand what each round is checking and what counts as OK.
